### Clínica de Diagnóstico de Negocio

* **Estudiante:** 
* **Caso de Negocio:** Predicción de Abandono de Clientes (Churn Prediction) en Telecomunicaciones.

### Descripción del Problema
Este proyecto implementa un modelo de Machine Learning (Random Forest) para predecir e identificar de forma temprana qué clientes tienen una alta probabilidad de abandonar la compañía de telecomunicaciones, basándose en su historial de reclamaciones, consumo y uso del servicio. Esto permite al área de negocio automatizar estrategias de retención eficaces.
